# Synthetic-only lab dataset

`activity4-synthetic-only.csv` is generated by [`ml/scripts/generate_synthetic.py`](../../scripts/generate_synthetic.py), using seed 182. Its adjacent manifest records the generator parameters and explicitly sets `measured_hardware` to `false`.

The file contains 12,000 generated rows: four trial groups per class, ten 100-sample windows per group, and three labels. The configured simulation cadence is 50 Hz. Amplitude and noise levels were chosen to exercise CSV validation, windowing, trial-group splitting, baseline/tree training, report export, and the Field Desk's synthetic provenance banner.

These values are not measured sensor data and do not model validated handling classes. The class patterns are intentionally separated, so resulting metrics must not be interpreted as product accuracy, safety evidence, or evidence of generalization to real parcels. Do not place this dataset in the firmware capture path.

Regenerate it with:

```sh
python3 ml/scripts/generate_synthetic.py \
  --output ml/data/synthetic/activity4-synthetic-only.csv \
  --seed 182
```
