## Third-party software

The project uses third-party packages and toolchains listed in `frontend/package-lock.json`, `platformio.ini`, and the PlatformIO environment. The firmware build obtains STM32CubeF4 and the FreeRTOS kernel/ARM_CM4F port from the pinned PlatformIO packages; those upstream sources are not original ParcelSense code. React, React DOM, Vite, TypeScript, and their transitive packages are third-party software bundled into the frontend build.

This file is an attribution placeholder, not a complete third-party license inventory. Before redistributing source or built artifacts, generate and review a license/SBOM inventory for the exact lockfiles and PlatformIO package revisions, include required upstream notices, and retain each vendor's terms. Do not copy vendor source into this repository without recording its origin and license.
